# Aster

Lecteur IPTV pour Android et Fire TV sous Fire OS, avec interface française adaptée au téléphone et à la télécommande.

## Télécharger

[Dernière version stable](https://github.com/armandgillot/aster-releases/releases/latest)

Télécharge le fichier APK de la dernière version. Le fichier update.json est utilisé par Aster pour vérifier les mises à jour ; il ne doit pas être installé.

Aster ne fournit ni abonnement ni flux IPTV. Configure tes propres sources Xtream Codes. Les identifiants sont enregistrés chiffrés sur ton appareil. La connexion HTTPS dépend également de l’adresse fournie par ton fournisseur.

## Mises à jour

Aster vérifie les mises à jour à l’ouverture, au maximum une fois par jour. Une vérification manuelle est disponible dans **Moi → Mises à jour**. Le téléchargement et l’installation nécessitent ton accord. Les mises à jour de production conservent les sources, profils, favoris et historiques.

Sur Android/Fire OS, l’autorisation d’installer des applications hors boutique peut être nécessaire. Les appareils Fire TV sous Vega OS ne sont pas compatibles avec cet APK Android.
